## Como Usar

### Acessar Documentação

1. **Interface Swagger UI**: 
   - URL: `http://localhost:3000/api-docs`
   - Interface interativa para testar endpoints
   - Suporte a autenticação JWT

2. **Especificação OpenAPI JSON**:
   - URL: `http://localhost:3000/api-docs/json`
   - Útil para integração com ferramentas externas
   - Pode ser usado para gerar SDKs

### Autenticação no Swagger

1. Acesse `/api/auth/login` e faça login
2. Copie o token retornado
3. Clique no botão "Authorize" no topo da página Swagger
4. Cole o token no formato: `Bearer {seu-token}`
5. Agora você pode testar endpoints protegidos

### Adicionar Documentação a Novos Endpoints

Use comentários JSDoc com anotações Swagger:

```typescript
/**
 * @swagger
 * /api/endpoint:
 *   get:
 *     tags:
 *       - Nome da Tag
 *     summary: Descrição breve
 *     description: Descrição detalhada
 *     security:
 *       - bearerAuth: []
 *     parameters:
 *       - in: query
 *         name: param
 *         schema:
 *           type: string
 *         description: Descrição do parâmetro
 *     responses:
 *       200:
 *         description: Sucesso
 *         content:
 *           application/json:
 *             schema:
 *               type: object
 */
router.get('/endpoint', ...);
```
