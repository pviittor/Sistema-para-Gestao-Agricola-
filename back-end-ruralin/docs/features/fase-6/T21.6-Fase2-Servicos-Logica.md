## Tarefas Detalhadas

### 1. ConsultoriaApplicationService

**Arquivo**: `src/application/services/consultoria/ConsultoriaApplicationService.ts`

**Métodos**:
- `list(page?, limit?): Promise<PaginatedResult<ConsultoriaResponseDto>>`
- `getById(id: number): Promise<ConsultoriaResponseDto>`
- `create(dto: CreateConsultoriaDto): Promise<ConsultoriaResponseDto>`
- `update(id: number, dto: UpdateConsultoriaDto): Promise<ConsultoriaResponseDto>`
- `delete(id: number): Promise<void>` (soft delete)
- `ativar(id: number): Promise<ConsultoriaResponseDto>`
- `desativar(id: number): Promise<ConsultoriaResponseDto>`
- `getTenants(id: number): Promise<TenantResponseDto[]>`
- `aumentarLimiteTenants(id: number, novoLimite: number): Promise<ConsultoriaResponseDto>`

**Regras de Negócio**:
- Apenas GOD pode criar/atualizar/desativar consultorias
- CNPJ deve ser único
- Desativar consultoria desativa todos os tenants (cascade)
- `tenantCount` é incrementado/decrementado automaticamente
- Apenas GOD pode aumentar limite

**Validações**:
- Verificar tipo de usuário (GOD)
- Validar CNPJ único
- Validar que consultoria existe antes de operações

**Cache**:
- `@Cacheable` em `list` e `getById`
- `@CacheEvict` em `create`, `update`, `delete`, `ativar`, `desativar`

**Auditoria**:
- `@Auditable` em todas as operações

**Transações**:
- `@Transactional` em `create`, `update`, `delete`, `desativar` (cascade)

### 2. TenantApplicationService

**Arquivo**: `src/application/services/tenant/TenantApplicationService.ts`

**Métodos**:
- `list(page?, limit?): Promise<PaginatedResult<TenantResponseDto>>`
- `getById(id: number): Promise<TenantResponseDto>`
- `create(dto: CreateTenantDto): Promise<TenantResponseDto>`
- `update(id: number, dto: UpdateTenantDto): Promise<TenantResponseDto>`
- `delete(id: number): Promise<void>` (soft delete)
- `findByConsultoria(consultoriaId: number): Promise<TenantResponseDto[]>`

**Regras de Negócio**:
- Apenas CONSULTOR pode criar tenants
- Tenant deve pertencer à consultoria do CONSULTOR
- Validar limite de tenants antes de criar
- Slug deve ser único globalmente
- Incrementar `tenantCount` na consultoria ao criar
- Decrementar `tenantCount` na consultoria ao deletar

**Validações**:
- Verificar tipo de usuário (CONSULTOR)
- Validar que consultoria existe e está ativa
- Validar que CONSULTOR pertence à consultoria
- Validar limite: `tenantCount < limiteTenants`
- Validar slug único

**Cache**:
- `@Cacheable` em `list`, `getById`, `findByConsultoria`
- `@CacheEvict` em `create`, `update`, `delete`

**Auditoria**:
- `@Auditable` em todas as operações

**Transações**:
- `@Transactional` em `create` (incrementar tenantCount), `delete` (decrementar tenantCount)

## Validações de Hierarquia

### Criação de Consultoria

```typescript
// Apenas GOD pode criar
if (user.tipo !== 'GOD') {
  throw new ForbiddenException('Apenas usuários GOD podem criar consultorias');
}
```

### Criação de Tenant

```typescript
// Apenas CONSULTOR pode criar
if (user.tipo !== 'CONSULTOR') {
  throw new ForbiddenException('Apenas consultores podem criar tenants');
}

// Validar que consultoria pertence ao CONSULTOR
if (dto.consultoriaId !== user.consultoriaId) {
  throw new ForbiddenException('Você só pode criar tenants na sua consultoria');
}
```

### Acesso a Dados

```typescript
// CONSULTOR só acessa seus tenants
if (user.tipo === 'CONSULTOR') {
  // Filtrar por consultoriaId
  const tenants = await this.tenantRepository.findByConsultoria(user.consultoriaId);
}
```

## Controle de Limites

### Limite de Tenants

```typescript
// Ao criar tenant
const consultoria = await this.consultoriaRepository.findById(dto.consultoriaId);
if (consultoria.tenantCount >= consultoria.limiteTenants) {
  throw new BadRequestException(
    `Limite de tenants excedido. Limite atual: ${consultoria.limiteTenants}`
  );
}

// Incrementar após criar
await this.consultoriaRepository.update(consultoria.id, {
  tenantCount: consultoria.tenantCount + 1
});
```

### Aumentar Limite (GOD)

```typescript
// Apenas GOD pode aumentar
if (user.tipo !== 'GOD') {
  throw new ForbiddenException('Apenas usuários GOD podem aumentar limite');
}

// Validar que novo limite >= tenantCount
if (novoLimite < consultoria.tenantCount) {
  throw new BadRequestException(
    `Novo limite deve ser >= quantidade atual de tenants (${consultoria.tenantCount})`
  );
}
```
