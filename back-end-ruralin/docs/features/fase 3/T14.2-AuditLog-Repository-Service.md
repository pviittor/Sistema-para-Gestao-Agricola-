## Arquivos Criados

### 1. `src/application/dto/auditLog/AuditLogQueryDto.ts`

DTOs para consulta de logs de auditoria.

**Interfaces**:
- `AuditLogQueryDto` - Filtros de consulta
- `AuditLogResponseDto` - DTO de resposta

**Campos de filtro**:
- `userId` - ID do usuário (opcional)
- `entity` - Nome da entidade (opcional)
- `entityId` - ID da entidade (opcional)
- `action` - Tipo de ação (opcional)
- `startDate` - Data de início (opcional)
- `endDate` - Data de fim (opcional)
- `ip` - IP de origem (opcional)
- `page` - Número da página (padrão: 1)
- `limit` - Limite de registros (padrão: 10)

### 2. `src/application/services/auditLog/IAuditLogQueryService.ts`

Interface para serviço de consulta de logs.

**Métodos**:
- `query(filters)` - Consulta com filtros avançados
- `findByUser(userId, page?, limit?)` - Busca por usuário
- `findByEntity(entity, entityId?, page?, limit?)` - Busca por entidade
- `findByAction(action, page?, limit?)` - Busca por ação
- `findByDateRange(startDate, endDate, page?, limit?)` - Busca por período
- `findByUserAndDateRange(userId, startDate, endDate, page?, limit?)` - Busca por usuário e período
- `getById(id)` - Busca por ID

### 3. `src/application/services/auditLog/AuditLogQueryService.ts`

Implementação do serviço de consulta.

**Características**:

## Funcionalidades Implementadas

### 1. Consulta com Filtros Avançados

Consulta logs com múltiplos filtros combinados.

```typescript
const result = await auditLogQueryService.query({
  userId: 1,
  entity: 'Usuario',
  action: 'UPDATE',
  startDate: new Date('2025-01-01'),
  endDate: new Date('2025-01-31'),
  page: 1,
  limit: 20
});
```

**Filtros suportados**:
- ✅ userId
- ✅ entity
- ✅ entityId
- ✅ action
- ✅ startDate / endDate
- ✅ ip

**Características**:
- Filtros são opcionais
- Múltiplos filtros podem ser combinados
- Paginação automática
- Ordenação por timestamp DESC

### 2. Busca por Usuário

Busca logs de um usuário específico.

```typescript
const result = await auditLogQueryService.findByUser(1, 1, 20);
```

**Características**:
- Paginação opcional
- Ordenação por timestamp DESC
- Retorna resultado paginado

### 3. Busca por Entidade

Busca logs de uma entidade específica.

```typescript
// Todos os logs da entidade
const result = await auditLogQueryService.findByEntity('Usuario');

// Logs de uma entidade específica
const result = await auditLogQueryService.findByEntity('Usuario', 123);
```

**Características**:
- entityId opcional
- Paginação opcional
- Ordenação por timestamp DESC

### 4. Busca por Ação

Busca logs por tipo de ação.

```typescript
const result = await auditLogQueryService.findByAction('DELETE', 1, 50);
```

**Características**:
- Suporta todas as ações (CREATE, UPDATE, DELETE, READ, LOGIN, LOGOUT)
- Paginação opcional
- Ordenação por timestamp DESC

### 5. Busca por Período

Busca logs em um período específico.

```typescript
const result = await auditLogQueryService.findByDateRange(
  new Date('2025-01-01'),
  new Date('2025-01-31'),
  1,
  100
);
```

**Características**:
- Suporta Date ou string
- Ajusta fim do dia automaticamente (23:59:59.999)
- Paginação opcional
- Ordenação por timestamp DESC

### 6. Busca por Usuário e Período

Busca logs de um usuário em um período específico.

```typescript
const result = await auditLogQueryService.findByUserAndDateRange(
  1,
  new Date('2025-01-01'),
  new Date('2025-01-31')
);
```

**Características**:
- Combina filtro de usuário e período
- Paginação opcional
- Ordenação por timestamp DESC

### 7. Busca por ID

Busca um log específico por ID.

```typescript
const log = await auditLogQueryService.getById(123);
```

**Características**:
- Retorna log único ou null
- Converte automaticamente para DTO

## Exemplos de Uso

### Exemplo 1: Consulta Completa com Filtros

```typescript
import { container } from '../core/di';
import { TYPES } from '../core/di/types';
import { IAuditLogQueryService } from '../application/services/auditLog';

const service = container.resolve<IAuditLogQueryService>(TYPES.IAuditLogQueryService);

const result = await service.query({
  userId: 1,
  entity: 'Usuario',
  action: 'UPDATE',
  startDate: '2025-01-01',
  endDate: '2025-01-31',
  page: 1,
  limit: 20
});

console.log(`Total: ${result.total}, Página: ${result.page}/${result.totalPages}`);
result.data.forEach(log => {
  console.log(`${log.action} em ${log.entity} (${log.entityId}) em ${log.timestamp}`);
});
```

### Exemplo 2: Buscar Logs de um Usuário

```typescript
const result = await service.findByUser(1, 1, 50);

console.log(`Usuário 1 tem ${result.total} logs`);
result.data.forEach(log => {
  console.log(`${log.action} em ${log.entity}`);
});
```

### Exemplo 3: Buscar Logs de Exclusões

```typescript
const result = await service.findByAction('DELETE', 1, 100);

console.log(`Total de exclusões: ${result.total}`);
result.data.forEach(log => {
  console.log(`Excluído: ${log.entity} (${log.entityId}) por usuário ${log.userId}`);
});
```

### Exemplo 4: Buscar Logs de um Período

```typescript
const result = await service.findByDateRange(
  new Date('2025-01-01'),
  new Date('2025-01-31')
);

console.log(`Logs em janeiro: ${result.total}`);
```

### Exemplo 5: Buscar Logs de um Usuário em um Período

```typescript
const result = await service.findByUserAndDateRange(
  1,
  '2025-01-01',
  '2025-01-31'
);

console.log(`Usuário 1 fez ${result.total} ações em janeiro`);
```

## Paginação

### Como Funciona

Todos os métodos de consulta suportam paginação:

- **page**: Número da página (padrão: 1, 1-indexed)
- **limit**: Limite de registros por página (padrão: 10)

**Exemplo**:
```typescript
// Primeira página, 10 registros
const page1 = await service.findByUser(1, 1, 10);

// Segunda página, 10 registros
const page2 = await service.findByUser(1, 2, 10);

// Primeira página, 50 registros
const page1Large = await service.findByUser(1, 1, 50);
```

### Resposta Paginada

```typescript
{
  data: [...],           // Array de logs da página
  total: 150,            // Total de registros
  page: 1,               // Página atual
  limit: 10,             // Limite por página
  totalPages: 15         // Total de páginas
}
```

## Performance

### Otimizações

1. **Índices**: Usa índices criados no modelo AuditLog
2. **Paginação no banco**: Usa `findAllPaginated` do BaseRepository
3. **Queries eficientes**: Filtros aplicados no banco de dados
4. **Ordenação**: Usa índice composto (userId, timestamp)

### Considerações

- **Volume**: Tabela pode ter muitos registros
- **Índices**: Importantes para performance
- **Limites**: Sempre usar limites apropriados
- **Cache**: Considerar cache para consultas frequentes (futuro)
