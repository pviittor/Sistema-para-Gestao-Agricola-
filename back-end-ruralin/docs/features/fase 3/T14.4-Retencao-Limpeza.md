## Contexto Técnico

### Por que Retenção e Limpeza?

**Necessidades de negócio**:
- **Espaço**: Logs podem crescer indefinidamente
- **Performance**: Tabelas grandes afetam performance
- **Custos**: Armazenamento tem custos
- **Compliance**: Políticas de retenção variam por empresa
- **Manutenção**: Limpeza manual é trabalhosa

**Casos de uso**:
- Limpar logs mais antigos que X dias
- Executar limpeza periodicamente (semanal/mensal)
- Manter apenas logs necessários para compliance
- Reduzir tamanho da tabela de logs

## Funcionalidades Implementadas

### 1. Método de Limpeza no Repositório

Método `deleteOlderThan` no `AuditLogRepository` para deletar logs antigos.

```typescript
async deleteOlderThan(cutoffDate: Date): Promise<number> {
  const result = await AuditLog.destroy({
    where: {
      timestamp: {
        [Op.lt]: cutoffDate,
      },
    },
  });
  return result;
}
```

**Características**:
- Usa Sequelize `destroy` para deleção eficiente
- Filtra por `timestamp < cutoffDate`
- Retorna número de registros deletados

### 2. Serviço de Limpeza

`AuditLogCleanupService` fornece lógica de limpeza.

**Métodos**:
- `cleanupOldLogs(retentionDays?)` - Executa limpeza
- `getRetentionDays()` - Obtém política atual
- `getCutoffDate(retentionDays?)` - Calcula data limite

**Configuração**:
- Variável de ambiente: `AUDIT_LOG_RETENTION_DAYS`
- Padrão: 365 dias (1 ano)
- Pode ser sobrescrito por parâmetro

### 3. Script de Execução

Script `cleanup-audit-logs.ts` para execução manual.

**Uso**:
```bash
npm run cleanup-audit-logs
```

**Características**:
- Inicializa DI container
- Mostra configuração antes de executar
- Executa limpeza
- Mostra resultados

**Valores recomendados**:

## Performance

### Considerações

- **Volume**: Pode deletar muitos registros de uma vez
- **Lock**: Operação pode bloquear tabela temporariamente
- **Tempo**: Pode levar tempo em tabelas grandes
- **Transação**: Operação é atômica (tudo ou nada)

### Otimizações

1. **Índice**: Usar índice em `timestamp` (já existe)
2. **Batch**: Considerar deleção em batches (futuro)
3. **Horário**: Executar em horário de baixo tráfego
4. **Monitoramento**: Monitorar tempo de execução

### Exemplo de Deleção em Batches (Futuro)

```typescript
async cleanupOldLogsInBatches(retentionDays: number, batchSize: number = 1000): Promise<number> {
  const cutoffDate = this.getCutoffDate(retentionDays);
  let totalDeleted = 0;
  
  while (true) {
    const deleted = await this.repository.deleteOlderThanInBatch(cutoffDate, batchSize);
    totalDeleted += deleted;
    
    if (deleted < batchSize) {
      break; // Não há mais registros para deletar
    }
    
    // Pequena pausa para não sobrecarregar o banco
    await new Promise(resolve => setTimeout(resolve, 100));
  }
  
  return totalDeleted;
}
```

**Fatores a considerar**:
