## Métodos da Interface

### Métodos CRUD

#### `findById(id: number | string): Promise<T | null>`
Busca uma entidade por ID.

**Parâmetros**:
- `id`: ID da entidade (número ou string)

**Retorno**: Promise que resolve com a entidade encontrada ou `null` se não existir

**Exemplo**:
```typescript
const usuario = await usuarioRepository.findById(1);
if (usuario) {
  console.log(usuario.nome);
}
```

#### `create(entity: Partial<T>): Promise<T>`
Cria uma nova entidade.

**Parâmetros**:
- `entity`: Dados parciais da entidade a ser criada

**Retorno**: Promise que resolve com a entidade criada

**Exemplo**:
```typescript
const novoUsuario = await usuarioRepository.create({
  nome: 'João Silva',
  email: 'joao@example.com',
  username: 'joao.silva'
});
```

#### `update(id: number | string, entity: Partial<T>): Promise<T>`
Atualiza uma entidade existente.

**Parâmetros**:
- `id`: ID da entidade a ser atualizada
- `entity`: Dados parciais a serem atualizados

**Retorno**: Promise que resolve com a entidade atualizada

**Exceções**: `NotFoundException` se a entidade não for encontrada

**Exemplo**:
```typescript
const usuarioAtualizado = await usuarioRepository.update(1, {
  nome: 'João Silva Atualizado'
});
```

#### `delete(id: number | string): Promise<boolean>`
Remove uma entidade.

**Parâmetros**:
- `id`: ID da entidade a ser removida

**Retorno**: Promise que resolve com `true` se a entidade foi removida, `false` se não existir

**Exemplo**:
```typescript
const removido = await usuarioRepository.delete(1);
if (removido) {
  console.log('Usuário removido com sucesso');
}
```

### Métodos de Query

#### `findAll(options?: FindOptions): Promise<T[]>`
Busca todas as entidades, opcionalmente com filtros.

**Parâmetros**:
- `options`: Opções de busca (filtros, ordenação, relacionamentos)

**Retorno**: Promise que resolve com array de entidades

**Exemplo**:
```typescript
const usuarios = await usuarioRepository.findAll({
  where: { tipo: 'ROOT' },
  order: [['nome', 'ASC']]
});
```

#### `findOne(options: FindOptions): Promise<T | null>`
Busca uma única entidade que atenda aos critérios.

**Parâmetros**:
- `options`: Opções de busca (filtros, relacionamentos)

**Retorno**: Promise que resolve com a entidade encontrada ou `null`

**Exemplo**:
```typescript
const usuario = await usuarioRepository.findOne({
  where: { email: 'usuario@example.com' }
});
```

#### `findMany(options: FindOptions): Promise<T[]>`
Busca múltiplas entidades que atendam aos critérios.

**Parâmetros**:
- `options`: Opções de busca (filtros, ordenação, relacionamentos)

**Retorno**: Promise que resolve com array de entidades

**Exemplo**:
```typescript
const eventos = await eventoRepository.findMany({
  where: { usuarioId: 1 },
  order: [['data', 'DESC']]
});
```

### Métodos de Paginação

#### `findAllPaginated(page: number, limit: number, options?: FindOptions): Promise<PaginatedResult<T>>`
Busca entidades com paginação.

**Parâmetros**:
- `page`: Número da página (1-indexed)
- `limit`: Limite de registros por página
- `options`: Opções de busca adicionais (filtros, ordenação, relacionamentos)

**Retorno**: Promise que resolve com resultado paginado

**Exemplo**:
```typescript
const result = await usuarioRepository.findAllPaginated(1, 10, {
  where: { tipo: 'ROOT' },
  order: [['nome', 'ASC']]
});

console.log(`Total: ${result.total}, Página: ${result.page}/${result.totalPages}`);
console.log(`Registros: ${result.data.length} de ${result.total}`);
```

## Tipos Auxiliares

### FindOptions

Interface para opções de busca em repositórios:

```typescript
interface FindOptions {
  where?: Record<string, any>;        // Condições WHERE
  include?: any[];                    // Relacionamentos a incluir
  order?: [string, 'ASC' | 'DESC'][]; // Ordenação
  attributes?: string[];              // Atributos específicos
  limit?: number;                     // Limite de resultados
  offset?: number;                    // Offset para paginação
}
```

**Exemplo de Uso**:
```typescript
const options: FindOptions = {
  where: { 
    status: 'ACTIVE',
    tipo: 'ROOT'
  },
  include: [
    { model: Role, as: 'roles' }
  ],
  order: [['createdAt', 'DESC']],
  attributes: ['id', 'nome', 'email']
};
```

### PaginatedResult

Interface para resultados paginados:

```typescript
interface PaginatedResult<T> {
  data: T[];          // Array de entidades
  total: number;      // Total de registros
  page: number;        // Página atual (1-indexed)
  limit: number;       // Limite por página
  totalPages: number;  // Total de páginas
}
```

**Exemplo de Uso**:
```typescript
const result: PaginatedResult<Usuario> = {
  data: [usuario1, usuario2, ...],
  total: 100,
  page: 1,
  limit: 10,
  totalPages: 10
};
```

## Padrão de Uso

### Criando um Repositório Específico

Repositórios específicos devem estender `IRepository<T>` e podem adicionar métodos customizados:

```typescript
import { IRepository } from '../../core/repository/IRepository';
import Usuario from '../../models/Usuario';

export interface IUsuarioRepository extends IRepository<Usuario> {
  findByEmail(email: string): Promise<Usuario | null>;
  findByUsername(username: string): Promise<Usuario | null>;
  findByTipo(tipo: string): Promise<Usuario[]>;
}
```

### Implementando um Repositório

A implementação concreta deve implementar todos os métodos da interface:

```typescript
import { injectable } from 'tsyringe';
import { IUsuarioRepository } from './IUsuarioRepository';
import { BaseRepository } from '../../core/repository/BaseRepository';
import Usuario from '../../models/Usuario';

@injectable()
export class UsuarioRepository extends BaseRepository<Usuario> implements IUsuarioRepository {
  constructor() {
    super(Usuario);
  }

  async findByEmail(email: string): Promise<Usuario | null> {
    return await this.findOne({ where: { email } });
  }

  async findByUsername(username: string): Promise<Usuario | null> {
    return await this.findOne({ where: { username } });
  }

  async findByTipo(tipo: string): Promise<Usuario[]> {
    return await this.findAll({ where: { tipo } });
  }
}
```

## Comparação: Antes vs Depois

### Antes (Acesso Direto ao Sequelize)

```typescript
// Controller
class UsuarioController {
  async index(req: Request, res: Response) {
    const usuarios = await Usuario.findAll({
      where: { tipo: 'ROOT' },
      order: [['nome', 'ASC']]
    });
    return res.json(usuarios);
  }

  async show(req: Request, res: Response) {
    const { id } = req.params;
    const usuario = await Usuario.findByPk(id);
    if (!usuario) {
      return res.status(404).json({ error: 'Usuário não encontrado' });
    }
    return res.json(usuario);
  }
}
```

**Problemas**:
- ❌ Controllers acoplados ao Sequelize
- ❌ Difícil de testar (precisa mockar Sequelize)
- ❌ Código duplicado em múltiplos controllers
- ❌ Difícil trocar ORM no futuro

### Depois (Com Repository Pattern)

```typescript
// Controller
@Injectable()
class UsuarioController {
  constructor(
    @Inject(TYPES.IUsuarioRepository)
    private repository: IUsuarioRepository
  ) {}

  async index(req: Request, res: Response) {
    const usuarios = await this.repository.findAll({
      where: { tipo: 'ROOT' },
      order: [['nome', 'ASC']]
    });
    return res.json(usuarios);
  }

  async show(req: Request, res: Response) {
    const { id } = req.params;
    const usuario = await this.repository.findById(id);
    if (!usuario) {
      throw new NotFoundException('Usuário', id);
    }
    return res.json(usuario);
  }
}
```

**Benefícios**:
- ✅ Controllers desacoplados do Sequelize
- ✅ Fácil de testar (mock do repository)
- ✅ Código reutilizável
- ✅ Fácil trocar implementação
