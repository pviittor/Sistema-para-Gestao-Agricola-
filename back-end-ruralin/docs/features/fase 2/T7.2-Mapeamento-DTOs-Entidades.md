# T7.2 - Mapeamento DTOs-Entidades - Documentação de Implementação

## Resumo Executivo

Criação do sistema de mapeamento entre DTOs e entidades do domínio, estabelecendo uma camada de conversão que mantém a separação entre a camada de aplicação (DTOs) e a camada de domínio (entidades). Este sistema garante que dados sensíveis não sejam expostos e que transformações necessárias sejam aplicadas.

## Decisões de Implementação

### Abordagem Escolhida

**Interface Genérica**:
- `IMapper<TEntity, TDto, TCreateDto, TUpdateDto>` define contrato padrão
- Métodos `toEntity` e `toDto` para conversão bidirecional
- `toEntity` é assíncrono para suportar operações como hash de senha

**Mapper Específico**:
- `UsuarioMapper` implementa a interface
- Aplica hash de senha no `toEntity` quando fornecida
- **NUNCA** inclui senha no `toDto`
- Trata campos opcionais corretamente

**Segurança**:
- Senha sempre hasheada ao converter de DTO para entidade
- Senha nunca exposta ao converter de entidade para DTO
- Dados sensíveis protegidos por padrão

Interface genérica que define o contrato padrão para mappers:

```typescript
export interface IMapper<TEntity, TDto, TCreateDto, TUpdateDto> {
  toEntity(dto: TCreateDto | TUpdateDto): Promise<Partial<TEntity>>;
  toDto(entity: TEntity): TDto;
}
```

**Características**:
- Genérica com 4 tipos: `TEntity`, `TDto`, `TCreateDto`, `TUpdateDto`
- `toEntity` assíncrono para suportar operações como hash
- `toDto` síncrono (apenas transformação de dados)

## Métodos Implementados

### `toEntity(dto: TCreateDto | TUpdateDto): Promise<Partial<TEntity>>`

Converte DTO para entidade do domínio, aplicando transformações necessárias.

**Implementação**:
```typescript
async toEntity(dto: CreateUsuarioDto | UpdateUsuarioDto): Promise<Partial<Usuario>> {
  const entity: any = {};

  // Campos básicos
  if ('nome' in dto && dto.nome !== undefined) entity.nome = dto.nome;
  if ('username' in dto && dto.username !== undefined) entity.username = dto.username;
  if ('email' in dto && dto.email !== undefined) entity.email = dto.email;
  // ... outros campos

  // Senha: aplicar hash se fornecida
  if ('senha' in dto && dto.senha) {
    entity.senha = await bcrypt.hash(dto.senha, 10);
  }

  return entity;
}
```

**Características**:
- Trata campos opcionais (verifica `undefined`)
- Aplica hash de senha se fornecida
- Retorna `Partial<TEntity>` para permitir atualizações parciais
- Assíncrono para suportar operações como hash

**Exemplo de Uso**:
```typescript
const mapper = new UsuarioMapper();
const dto: CreateUsuarioDto = {
  nome: 'João',
  email: 'joao@example.com',
  senha: 'Senha123',
  // ...
};
const entity = await mapper.toEntity(dto);
// entity.senha será o hash da senha
```

### `toDto(entity: TEntity): TDto`

Converte entidade do domínio para DTO, **excluindo dados sensíveis**.

**Implementação**:
```typescript
toDto(entity: Usuario): UsuarioResponseDto {
  return {
    id: entity.id,
    nome: entity.nome,
    username: entity.username,
    email: entity.email,
    whatsapp: entity.whatsapp,
    tipo: entity.tipo as any,
    apiKey: entity.apiKey,
    apiUrl: entity.apiUrl,
    createdAt: entity.createdAt,
    updatedAt: entity.updatedAt,
    // NUNCA incluir senha!
  };
}
```

**Características**:
- **NUNCA** inclui senha ou outros dados sensíveis
- Inclui apenas campos necessários para resposta
- Síncrono (apenas transformação de dados)
- Type-safe

**Exemplo de Uso**:
```typescript
const mapper = new UsuarioMapper();
const entity: Usuario = {
  id: 1,
  nome: 'João',
  email: 'joao@example.com',
  senha: 'hashed_password',
  // ...
};
const dto = mapper.toDto(entity);
// dto NÃO terá campo senha
```

## Segurança

### Proteção de Dados Sensíveis

**Regra Fundamental**: Mappers **NUNCA** devem expor dados sensíveis em DTOs.

**Dados Sensíveis**:
- Senhas
- Tokens de autenticação
- Chaves privadas
- Informações pessoais sensíveis

**Exemplo**:
```typescript
toDto(entity: Usuario): UsuarioResponseDto {
  return {
    // ... campos públicos
    // NUNCA incluir: senha, tokens, etc.
  };
}
```

### Hash de Senha

O `UsuarioMapper` aplica hash de senha automaticamente:

```typescript
if ('senha' in dto && dto.senha) {
  entity.senha = await bcrypt.hash(dto.senha, 10);
}
```

**Características**:
- Hash aplicado apenas se senha fornecida
- Usa bcrypt com salt rounds = 10
- Senha original nunca armazenada

## Integração com Application Services

### Uso em Application Services

Application Services devem usar mappers para conversão:

```typescript
@Injectable()
export class UsuarioApplicationService {
  constructor(
    @Inject(TYPES.IUsuarioRepository)
    private repository: IUsuarioRepository,
    @Inject(TYPES.IUsuarioMapper) // Se registrado no DI
    private mapper: UsuarioMapper
  ) {}

  async create(dto: CreateUsuarioDto): Promise<UsuarioResponseDto> {
    const entity = await this.mapper.toEntity(dto);
    const created = await this.repository.create(entity);
    return this.mapper.toDto(created);
  }

  async getById(id: number): Promise<UsuarioResponseDto | null> {
    const entity = await this.repository.findById(id);
    return entity ? this.mapper.toDto(entity) : null;
  }
}
```

**Alternativa (sem DI)**:
```typescript
// Se mapper não for injetado, pode ser usado como classe estática
const mapper = new UsuarioMapper();
const entity = await mapper.toEntity(dto);
```

## Testes Unitários

### Estrutura de Testes

Os testes verificam:
1. **toEntity com CreateUsuarioDto**: Conversão completa com hash de senha
2. **toEntity com UpdateUsuarioDto**: Campos opcionais
3. **toEntity com senha**: Hash aplicado corretamente
4. **toEntity sem senha**: Senha não incluída
5. **toDto**: Senha nunca exposta
6. **toDto**: Todos os campos públicos incluídos

### Exemplo de Teste

```typescript
describe('UsuarioMapper', () => {
  let mapper: UsuarioMapper;

  beforeEach(() => {
    mapper = new UsuarioMapper();
  });

  it('deve converter CreateUsuarioDto para entidade com hash de senha', async () => {
    const dto: CreateUsuarioDto = {
      nome: 'João',
      email: 'joao@example.com',
      senha: 'Senha123',
      // ...
    };

    const entity = await mapper.toEntity(dto);

    expect(entity.senha).toBeDefined();
    expect(entity.senha).not.toBe('Senha123'); // Deve ser hash
    expect(bcrypt.hash).toHaveBeenCalledWith('Senha123', 10);
  });

  it('não deve incluir senha no DTO', () => {
    const entity = {
      id: 1,
      nome: 'João',
      senha: 'hashed_password',
      // ...
    } as Usuario;

    const dto = mapper.toDto(entity);

    expect((dto as any).senha).toBeUndefined();
  });
});
```

## Comparação: Antes vs Depois

### Antes (Mapeamento Manual)

```typescript
@Injectable()
export class UsuarioApplicationService {
  async create(dto: CreateUsuarioDto): Promise<UsuarioResponseDto> {
    // Mapeamento manual no service ❌
    const entity: any = {
      nome: dto.nome,
      email: dto.email,
      senha: await bcrypt.hash(dto.senha, 10),
      // ...
    };
    
    const created = await this.repository.create(entity);
    
    // Mapeamento manual para DTO ❌
    const dto: UsuarioResponseDto = {
      id: created.id,
      nome: created.nome,
      email: created.email,
      // ... (esqueceu de remover senha?)
    };
    
    return dto;
  }
}
```

**Problemas**:
- ❌ Mapeamento duplicado em múltiplos lugares
- ❌ Fácil esquecer de remover senha
- ❌ Difícil manter consistência
- ❌ Código repetitivo

### Depois (Com Mapper)

```typescript
@Injectable()
export class UsuarioApplicationService {
  constructor(
    @Inject(TYPES.IUsuarioRepository)
    private repository: IUsuarioRepository,
    private mapper: UsuarioMapper
  ) {}

  async create(dto: CreateUsuarioDto): Promise<UsuarioResponseDto> {
    // Usa mapper para conversão ✅
    const entity = await this.mapper.toEntity(dto);
    const created = await this.repository.create(entity);
    return this.mapper.toDto(created);
  }
}
```

**Benefícios**:
- ✅ Mapeamento centralizado
- ✅ Senha sempre protegida
- ✅ Código limpo e reutilizável
- ✅ Fácil manter consistência

## Padrões e Convenções

### Nomenclatura

**Interface**:
- Padrão: `IMapper` (genérica)
- Interface específica: `I[Entity]Mapper` (opcional)

**Classe**:
- Padrão: `[Entity]Mapper`
- Exemplo: `UsuarioMapper`, `EventoMapper`

**Arquivo**:
- Padrão: `[Entity]Mapper.ts`
- Exemplo: `UsuarioMapper.ts`

### Métodos Padrão

Todos os mappers devem implementar:

1. **`toEntity(dto: TCreateDto | TUpdateDto): Promise<Partial<TEntity>>`**
   - Converte DTO para entidade
   - Aplica transformações (hash, formatação, etc.)
   - Retorna `Partial<TEntity>` para permitir atualizações parciais

2. **`toDto(entity: TEntity): TDto`**
   - Converte entidade para DTO
   - **NUNCA** inclui dados sensíveis
   - Inclui apenas campos necessários

### Regras de Segurança

1. **NUNCA incluir senha em DTOs**
2. **Sempre aplicar hash de senha no toEntity**
3. **Verificar campos opcionais antes de incluir**
4. **Não expor dados internos do sistema**
