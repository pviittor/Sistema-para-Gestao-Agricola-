## Decisões de Implementação

### Abordagem Escolhida

**Classe Abstrata com Generics**:
- Utilização de generics (`BaseRepository<T extends Model>`) para type safety
- Classe abstrata permite que repositórios específicos estendam e adicionem métodos customizados
- Integração direta com Sequelize usando `ModelStatic<T>`
- Decorator `@Injectable` para integração com DI container

**Tratamento de Erros**:
- Uso de `NotFoundException` para entidades não encontradas em `update`
- Retorno de `false` em `delete` quando entidade não existe (não lança exceção)
- Mensagens de erro contextuais com nome do modelo

## Métodos Implementados

### Métodos CRUD

#### `findById(id: number | string): Promise<T | null>`

Busca uma entidade por ID usando `findByPk` do Sequelize.

**Implementação**:
```typescript
async findById(id: number | string): Promise<T | null> {
  return await this.model.findByPk(id);
}
```

**Exemplo de Uso**:
```typescript
const usuario = await usuarioRepository.findById(1);
if (usuario) {
  console.log(usuario.nome);
}
```

#### `create(entity: Partial<T>): Promise<T>`

Cria uma nova entidade usando `create` do Sequelize.

**Implementação**:
```typescript
async create(entity: Partial<T>): Promise<T> {
  return await this.model.create(entity as any);
}
```

**Exemplo de Uso**:
```typescript
const novoUsuario = await usuarioRepository.create({
  nome: 'João Silva',
  email: 'joao@example.com',
  username: 'joao.silva'
});
```

#### `update(id: number | string, entity: Partial<T>): Promise<T>`

Atualiza uma entidade existente. Lança `NotFoundException` se a entidade não for encontrada.

**Implementação**:
```typescript
async update(id: number | string, entity: Partial<T>): Promise<T> {
  const instance = await this.findById(id);
  
  if (!instance) {
    const modelName = (this.model as any).name || 'Entidade';
    throw new NotFoundException(modelName, id);
  }
  
  await instance.update(entity);
  return instance;
}
```

**Exemplo de Uso**:
```typescript
try {
  const usuarioAtualizado = await usuarioRepository.update(1, {
    nome: 'João Silva Atualizado'
  });
} catch (error) {
  if (error instanceof NotFoundException) {
    // Tratar entidade não encontrada
  }
}
```

#### `delete(id: number | string): Promise<boolean>`

Remove uma entidade. Retorna `false` se a entidade não existir (não lança exceção).

**Implementação**:
```typescript
async delete(id: number | string): Promise<boolean> {
  const instance = await this.findById(id);
  
  if (!instance) {
    return false;
  }
  
  await instance.destroy();
  return true;
}
```

**Exemplo de Uso**:
```typescript
const removido = await usuarioRepository.delete(1);
if (removido) {
  console.log('Usuário removido com sucesso');
} else {
  console.log('Usuário não encontrado');
}
```

### Métodos de Query

#### `findAll(options?: FindOptions): Promise<T[]>`

Busca todas as entidades, opcionalmente com filtros.

**Implementação**:
```typescript
async findAll(options?: FindOptions): Promise<T[]> {
  return await this.model.findAll({
    where: options?.where,
    include: options?.include,
    order: options?.order,
    attributes: options?.attributes,
  });
}
```

**Exemplo de Uso**:
```typescript
const usuarios = await usuarioRepository.findAll({
  where: { tipo: 'ROOT' },
  order: [['nome', 'ASC']]
});
```

#### `findOne(options: FindOptions): Promise<T | null>`

Busca uma única entidade que atenda aos critérios.

**Implementação**:
```typescript
async findOne(options: FindOptions): Promise<T | null> {
  return await this.model.findOne({
    where: options.where,
    include: options.include,
    order: options.order,
    attributes: options.attributes,
  });
}
```

**Exemplo de Uso**:
```typescript
const usuario = await usuarioRepository.findOne({
  where: { email: 'usuario@example.com' }
});
```

#### `findMany(options: FindOptions): Promise<T[]>`

Busca múltiplas entidades. Atualmente chama `findAll` internamente.

**Implementação**:
```typescript
async findMany(options: FindOptions): Promise<T[]> {
  return await this.findAll(options);
}
```

### Métodos de Paginação

#### `findAllPaginated(page: number, limit: number, options?: FindOptions): Promise<PaginatedResult<T>>`

Busca entidades com paginação usando `findAndCountAll` do Sequelize.

**Implementação**:
```typescript
async findAllPaginated(
  page: number,
  limit: number,
  options?: FindOptions
): Promise<PaginatedResult<T>> {
  const offset = (page - 1) * limit;
  
  const { rows, count } = await this.model.findAndCountAll({
    where: options?.where,
    include: options?.include,
    order: options?.order,
    attributes: options?.attributes,
    limit,
    offset,
  });

  return {
    data: rows,
    total: count,
    page,
    limit,
    totalPages: Math.ceil(count / limit),
  };
}
```

**Exemplo de Uso**:
```typescript
const result = await usuarioRepository.findAllPaginated(1, 10, {
  where: { tipo: 'ROOT' },
  order: [['nome', 'ASC']]
});

console.log(`Total: ${result.total}`);
console.log(`Página: ${result.page}/${result.totalPages}`);
console.log(`Registros: ${result.data.length}`);
```

**Cálculo de Offset**:
- Página 1, limite 10: offset = 0
- Página 2, limite 10: offset = 10
- Página 3, limite 10: offset = 20

## Padrão de Uso

### Criando um Repositório Específico

Repositórios específicos devem estender `BaseRepository<T>` e passar o modelo Sequelize:

```typescript
import { Injectable } from '../../core/di';
import { BaseRepository } from '../../core/repository/BaseRepository';
import Usuario from '../../models/Usuario';

@Injectable()
export class UsuarioRepository extends BaseRepository<Usuario> {
  constructor() {
    super(Usuario);
  }

  // Métodos customizados específicos do Usuario
  async findByEmail(email: string): Promise<Usuario | null> {
    return await this.findOne({ where: { email } });
  }

  async findByUsername(username: string): Promise<Usuario | null> {
    return await this.findOne({ where: { username } });
  }
}
```

### Registrando no DI Container

O repositório deve ser registrado no container de DI:

```typescript
// src/core/di/registerRepositories.ts
import { container } from './container';
import { TYPES } from './types';
import { UsuarioRepository } from '../../infrastructure/repository/UsuarioRepository';

export function registerRepositories(): void {
  container.registerSingleton(TYPES.IUsuarioRepository, UsuarioRepository);
}
```

### Usando em Application Services

```typescript
import { Injectable, Inject } from '../../core/di';
import { TYPES } from '../../core/di/types';
import { IUsuarioRepository } from '../../infrastructure/repository/IUsuarioRepository';

@Injectable()
export class UsuarioApplicationService {
  constructor(
    @Inject(TYPES.IUsuarioRepository)
    private repository: IUsuarioRepository
  ) {}

  async getById(id: number) {
    const usuario = await this.repository.findById(id);
    if (!usuario) {
      throw new NotFoundException('Usuário', id);
    }
    return usuario;
  }
}
```

## Tratamento de Erros

### NotFoundException em Update

O método `update` lança `NotFoundException` quando a entidade não é encontrada:

```typescript
async update(id: number | string, entity: Partial<T>): Promise<T> {
  const instance = await this.findById(id);
  
  if (!instance) {
    const modelName = (this.model as any).name || 'Entidade';
    throw new NotFoundException(modelName, id);
  }
  
  await instance.update(entity);
  return instance;
}
```

**Comportamento**:
- Se entidade existe: atualiza e retorna
- Se entidade não existe: lança `NotFoundException` com nome do modelo e ID

### Delete Retorna Boolean

O método `delete` retorna `boolean` ao invés de lançar exceção:

```typescript
async delete(id: number | string): Promise<boolean> {
  const instance = await this.findById(id);
  
  if (!instance) {
    return false; // Não lança exceção
  }
  
  await instance.destroy();
  return true;
}
```

**Comportamento**:
- Se entidade existe: remove e retorna `true`
- Se entidade não existe: retorna `false` (não lança exceção)

**Razão**: Permite que o código chamador decida como tratar a situação (exceção ou verificação de retorno).

### Exemplo de Teste

```typescript
describe('BaseRepository', () => {
  let mockModel: ModelStatic<MockModel>;
  let repository: TestRepository;

  beforeEach(() => {
    mockModel = {
      findByPk: jest.fn(),
      findAll: jest.fn(),
      // ...
    } as any;

    repository = new TestRepository(mockModel);
  });

  it('deve retornar a entidade quando encontrada', async () => {
```

## Comparação: Antes vs Depois

### Antes (Sem BaseRepository)

```typescript
// Cada repositório implementa tudo do zero
class UsuarioRepository {
  private model = Usuario;

  async findById(id: number) {
    return await this.model.findByPk(id);
  }

  async findAll(options?: any) {
    return await this.model.findAll(options);
  }

  async create(entity: any) {
    return await this.model.create(entity);
  }

  // ... repetição em cada repositório
}

class EventoRepository {
  private model = Evento;

  async findById(id: number) {
    return await this.model.findByPk(id);
  }

  // ... mesma lógica repetida
}
```

**Problemas**:
- ❌ Código duplicado em cada repositório
- ❌ Difícil manter consistência
- ❌ Mudanças requerem atualizar múltiplos arquivos

### Depois (Com BaseRepository)

```typescript
// BaseRepository implementa tudo uma vez
abstract class BaseRepository<T> {
  // Implementação comum
}

// Repositórios específicos apenas estendem
class UsuarioRepository extends BaseRepository<Usuario> {
  constructor() {
    super(Usuario);
  }

  // Apenas métodos customizados
  async findByEmail(email: string) {
    return await this.findOne({ where: { email } });
  }
}
```

**Benefícios**:
- ✅ Código reutilizado
- ✅ Consistência garantida
- ✅ Mudanças em um lugar afetam todos
