## Métodos Implementados

### Métodos Customizados

#### `findByLocal(localId: number): Promise<Evento[]>`

Busca todos os eventos de um local específico, ordenados por data e horário de início.

**Implementação**:
```typescript
async findByLocal(localId: number): Promise<Evento[]> {
  return await this.findAll({

  });
}
```

**Exemplo de Uso**:
```typescript
const eventos = await eventoRepository.findByLocal(1);
console.log(`Encontrados ${eventos.length} eventos no local`);
```

**Casos de Uso**:
- Listar eventos de um local específico
- Filtrar eventos por local
- Relatórios por local

#### `findByData(dataInicio: Date | string, dataFim: Date | string): Promise<Evento[]>`

Busca eventos em um período de datas, ordenados por data e horário de início.

**Implementação**:
```typescript
async findByData(dataInicio: Date | string, dataFim: Date | string): Promise<Evento[]> {
  // Converter para string no formato YYYY-MM-DD se necessário
  const dataInicioStr = dataInicio instanceof Date 
    ? dataInicio.toISOString().split('T')[0]
    : dataInicio;
  const dataFimStr = dataFim instanceof Date
    ? dataFim.toISOString().split('T')[0]
    : dataFim;

  return await this.findAll({
    where: {
      data: {
        [Op.between]: [dataInicioStr, dataFimStr],
      },
    },
    order: [['data', 'ASC'], ['horario_inicio', 'ASC']],
  });
}
```

**Exemplo de Uso**:
```typescript
// Com Date
const eventos = await eventoRepository.findByData(
  new Date('2025-01-01'),
  new Date('2025-01-31')
);

// Com string
const eventos = await eventoRepository.findByData(
  '2025-01-01',
  '2025-01-31'
);
```

**Casos de Uso**:
- Calendário de eventos
- Relatórios por período
- Busca de eventos futuros
- Histórico de eventos

## Detalhes de Implementação

### Busca por Local

O método `findByLocal` utiliza `findAll` com filtro `where: { localId }` e ordenação:

```typescript
async findByLocal(localId: number): Promise<Evento[]> {
  return await this.findAll({
    where: { localId },
    order: [['data', 'ASC'], ['horario_inicio', 'ASC']],
  });
}
```

**Características**:
- Filtra eventos pelo `localId`
- Ordena por data (crescente) e depois por horário de início (crescente)
- Retorna array vazio se não houver eventos

### Busca por Período de Datas

O método `findByData` utiliza `Op.between` do Sequelize para buscar eventos no intervalo:

```typescript
async findByData(dataInicio: Date | string, dataFim: Date | string): Promise<Evento[]> {
  // Conversão automática de Date para string
  const dataInicioStr = dataInicio instanceof Date 
    ? dataInicio.toISOString().split('T')[0]
    : dataInicio;
  const dataFimStr = dataFim instanceof Date
    ? dataFim.toISOString().split('T')[0]
    : dataFim;

  return await this.findAll({
    where: {
      data: {
        [Op.between]: [dataInicioStr, dataFimStr],
      },
    },
    order: [['data', 'ASC'], ['horario_inicio', 'ASC']],
  });
}
```

**Características**:
- Aceita `Date` ou `string` como parâmetros
- Converte automaticamente `Date` para formato `YYYY-MM-DD`
- Usa `Op.between` para busca inclusiva (inclui dataInicio e dataFim)
- Ordena por data e horário de início
- Retorna array vazio se não houver eventos no período

**Importante**: O `Op.between` é inclusivo, ou seja, inclui tanto a data de início quanto a data de fim.

describe('EventoRepository', () => {

## Comparação: Antes vs Depois

### Antes (Acesso Direto ao Sequelize)

```typescript
// Controller
class EventoController {
  async getByLocal(req: Request, res: Response) {
    const { localId } = req.params;
    
    // Acesso direto ao Sequelize
    const eventos = await Evento.findAll({
      where: { localId },
      order: [['data', 'ASC']]
    });
    
    return res.json(eventos);
  }
}
```

**Problemas**:
- ❌ Controller acoplado ao Sequelize
- ❌ Código duplicado em múltiplos lugares
- ❌ Difícil de testar

### Depois (Com Repository Pattern)

```typescript
// Controller
@Injectable()
class EventoController {
  constructor(
    @Inject(TYPES.IEventoRepository)
    private eventoRepository: IEventoRepository
  ) {}

  async getByLocal(req: Request, res: Response) {
    const { localId } = req.params;
    
    // Uso do repositório
    const eventos = await this.eventoRepository.findByLocal(Number(localId));
    
    return res.json(eventos);
  }
}
```

**Benefícios**:
- ✅ Controller desacoplado do Sequelize
- ✅ Código reutilizável
- ✅ Fácil de testar
