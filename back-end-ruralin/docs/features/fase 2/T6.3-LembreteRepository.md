## Métodos Implementados

### Métodos Customizados

#### `findByUsuario(usuarioId: number): Promise<Lembrete[]>`

Busca todos os lembretes de um usuário específico, incluindo os relacionamentos com `LembreteDataHora`.

**Implementação**:
```typescript
async findByUsuario(usuarioId: number): Promise<Lembrete[]> {
  return await this.findAll({
    where: { usuarioId },
    include: [
      {
        model: LembreteDataHora,
        as: 'lembrete_data_hora',
        required: false,
      },
    ],
    order: [['createdAt', 'DESC']],
  });
}
```

**Exemplo de Uso**:
```typescript
const lembretes = await lembreteRepository.findByUsuario(1);
console.log(`Encontrados ${lembretes.length} lembretes do usuário`);
```

**Características**:
- Filtra lembretes pelo `usuarioId`
- Inclui relacionamento com `LembreteDataHora` (opcional, não obrigatório)
- Ordena por data de criação (mais recentes primeiro)
- Retorna array vazio se não houver lembretes

**Casos de Uso**:
- Listar lembretes de um usuário
- Dashboard do usuário
- Histórico de lembretes

#### `findProximos(limite?: number): Promise<Lembrete[]>`

Busca os próximos lembretes baseado nas datas/horários dos `LembreteDataHora` relacionados.

**Implementação**:
```typescript
async findProximos(limite: number = 10): Promise<Lembrete[]> {
  const hoje = new Date();
  hoje.setHours(0, 0, 0, 0);
  const hojeStr = hoje.toISOString().split('T')[0];

  const resultados = await this.model.findAll({
    include: [
      {
        model: LembreteDataHora,
        as: 'lembrete_data_hora',
        required: true,
        where: {
          [Op.or]: [
            {
              data: {
                [Op.gte]: hojeStr,
              },
            },
            {
              data: null,
              dia: {
                [Op.ne]: null,
              },
            },
          ],
        },
      },
    ],
    order: [
      [LembreteDataHora, 'data', 'ASC'],
      [LembreteDataHora, 'horario', 'ASC'],
    ] as any,
    limit: limite,
  });

  return resultados as Lembrete[];
}
```

**Exemplo de Uso**:
```typescript
// Buscar próximos 5 lembretes
const proximos = await lembreteRepository.findProximos(5);

// Usar limite padrão (10)
const proximos = await lembreteRepository.findProximos();
```

**Lógica de Filtro**:
- Busca lembretes com `LembreteDataHora` onde:
  - `data >= hoje` (lembretes com data futura ou hoje) OU
  - `data` é null mas `dia` está definido (lembretes recorrentes por dia da semana)
- Ordena por data (crescente) e depois por horário (crescente)
- Limita o número de resultados retornados

**Características**:
- Filtra apenas lembretes futuros ou recorrentes
- Ordena por data e horário dos `LembreteDataHora`
- Limite padrão de 10 se não especificado
- Retorna array vazio se não houver lembretes próximos

**Casos de Uso**:
- Dashboard com próximos lembretes
- Notificações de lembretes
- Calendário de lembretes
- Widget de lembretes pendentes

## Detalhes de Implementação

### Busca por Usuário

O método `findByUsuario` utiliza `findAll` do BaseRepository com include opcional:

```typescript
include: [
  {
    model: LembreteDataHora,
    as: 'lembrete_data_hora',
    required: false, // LEFT JOIN - inclui lembretes mesmo sem LembreteDataHora
  },
]
```

**Características**:
- Filtra lembretes pelo `usuarioId`
- Inclui `LembreteDataHora` relacionado (opcional)
- Ordena por data de criação (mais recentes primeiro)

### Busca de Próximos Lembretes

O método `findProximos` utiliza acesso direto ao modelo para flexibilidade na ordenação:

```typescript
const resultados = await this.model.findAll({
  include: [
    {
      model: LembreteDataHora,
      as: 'lembrete_data_hora',
      required: true, // INNER JOIN - apenas lembretes com LembreteDataHora
      where: {
        [Op.or]: [
          { data: { [Op.gte]: hojeStr } }, // Data futura ou hoje
          { data: null, dia: { [Op.ne]: null } }, // Recorrente por dia
        ],
      },
    },
  ],
  order: [
    [LembreteDataHora, 'data', 'ASC'],
    [LembreteDataHora, 'horario', 'ASC'],
  ] as any,
  limit: limite,
});
```

**Características**:
- Filtra apenas lembretes com `LembreteDataHora` (required: true)
- Filtra por data futura ou recorrentes
- Ordena por data e horário dos `LembreteDataHora`
- Usa `as any` para contornar limitações de tipo do TypeScript com Sequelize

**Nota**: O uso de `as any` na ordenação é necessário devido a limitações de tipagem do Sequelize com TypeScript quando se ordena por campos de modelos relacionados. A funcionalidade está correta, apenas a tipagem é mais flexível.

## Comparação: Antes vs Depois

### Antes (Acesso Direto ao Sequelize)

```typescript
// Controller
class LembreteController {
  async getByUsuario(req: Request, res: Response) {
    const { usuarioId } = req.params;
    
    // Acesso direto ao Sequelize
    const lembretes = await Lembrete.findAll({
      where: { usuarioId },
      include: [{ model: LembreteDataHora, as: 'lembrete_data_hora' }],
    });
    
    return res.json(lembretes);
  }
}
```

**Problemas**:
- ❌ Controller acoplado ao Sequelize
- ❌ Código duplicado em múltiplos lugares
- ❌ Difícil de testar

### Depois (Com Repository Pattern)

```typescript
// Controller
@Injectable()
class LembreteController {
  constructor(
    @Inject(TYPES.ILembreteRepository)
    private lembreteRepository: ILembreteRepository
  ) {}

  async getByUsuario(req: Request, res: Response) {
    const { usuarioId } = req.params;
    
    // Uso do repositório
    const lembretes = await this.lembreteRepository.findByUsuario(Number(usuarioId));
    
    return res.json(lembretes);
  }
}
```

**Benefícios**:
- ✅ Controller desacoplado do Sequelize
- ✅ Código reutilizável
- ✅ Fácil de testar
