Implementação do repositório:

```typescript
@Injectable()
export class UsuarioRepository extends BaseRepository<Usuario> implements IUsuarioRepository {
  constructor() {
    super(Usuario);
  }

  async findByEmail(email: string): Promise<Usuario | null> {
    return await this.findOne({ where: { email } });
  }

  async findByUsername(username: string): Promise<Usuario | null> {

  }
}
```

## Padrão de Uso

### Criando um Novo Repositório

O `UsuarioRepository` serve como exemplo para criar outros repositórios:

1. **Criar Interface**:
```typescript
// src/infrastructure/repository/IEventoRepository.ts
export interface IEventoRepository extends IRepository<Evento> {
  findByLocal(localId: number): Promise<Evento[]>;
  findByData(dataInicio: Date, dataFim: Date): Promise<Evento[]>;
}
```

2. **Criar Implementação**:
```typescript
// src/infrastructure/repository/EventoRepository.ts
@Injectable()
export class EventoRepository extends BaseRepository<Evento> implements IEventoRepository {
  constructor() {
    super(Evento);
  }

  async findByLocal(localId: number): Promise<Evento[]> {
    return await this.findAll({ where: { localId } });
  }

  async findByData(dataInicio: Date, dataFim: Date): Promise<Evento[]> {
    return await this.findAll({
      where: {
        data: {
          [Op.between]: [dataInicio, dataFim]
        }
      }
    });
  }
}
```

3. **Registrar no DI Container**:
```typescript
// src/core/di/registerRepositories.ts
container.registerSingleton(TYPES.IEventoRepository, EventoRepository);
```

## Testes Unitários

### Estrutura de Testes

Os testes verificam:
1. **findByEmail**: Retorna usuário quando encontrado, null quando não encontrado
2. **findByUsername**: Retorna usuário quando encontrado, null quando não encontrado
3. **Métodos herdados**: Verifica que métodos do BaseRepository estão disponíveis

### Exemplo de Teste

```typescript
describe('UsuarioRepository', () => {
  let repository: UsuarioRepository;
  let mockFindOne: jest.Mock;

  beforeEach(() => {
    repository = new UsuarioRepository();
    mockFindOne = jest.fn();
    (repository as any).findOne = mockFindOne;
  });

  it('deve retornar usuário quando encontrado por email', async () => {
    const mockUsuario = { id: 1, email: 'usuario@example.com' } as Usuario;
    mockFindOne.mockResolvedValue(mockUsuario);

    const result = await repository.findByEmail('usuario@example.com');

    expect(result).toBe(mockUsuario);
    expect(mockFindOne).toHaveBeenCalledWith({
      where: { email: 'usuario@example.com' },
    });
  });
});
```

## Comparação: Antes vs Depois

### Antes (Acesso Direto ao Sequelize)

```typescript
// Controller
class AuthController {
  async authenticate(req: Request, res: Response) {
    const { email, senha } = req.body;
    
    // Acesso direto ao Sequelize
    const user = await Usuario.findOne({ where: { email } });
    
    if (!user) {
      return res.status(401).json({ error: 'Credenciais inválidas' });
    }
    
    // ...
  }
}
```

**Problemas**:
- ❌ Controller acoplado ao Sequelize
- ❌ Difícil de testar (precisa mockar Sequelize)
- ❌ Código duplicado em múltiplos lugares
- ❌ Difícil trocar ORM no futuro

### Depois (Com Repository Pattern)

```typescript
// Controller
@Injectable()
class AuthController {
  constructor(
    @Inject(TYPES.IUsuarioRepository)
    private usuarioRepository: IUsuarioRepository
  ) {}

  async authenticate(req: Request, res: Response) {
    const { email, senha } = req.body;
    
    // Uso do repositório
    const user = await this.usuarioRepository.findByEmail(email);
    
    if (!user) {
      throw new UnauthorizedException('Credenciais inválidas');
    }
    
    // ...
  }
}
```

**Benefícios**:
- ✅ Controller desacoplado do Sequelize
- ✅ Fácil de testar (mock do repository)
- ✅ Código reutilizável
- ✅ Fácil trocar implementação
