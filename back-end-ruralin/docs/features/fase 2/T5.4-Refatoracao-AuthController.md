## Decisões de Implementação

### Abordagem Escolhida

**Injeção de Dependência via Constructor**:
- `IUsuarioRepository` injetado no construtor usando `@Inject(TYPES.IUsuarioRepository)`
- Mantém o decorator `@Injectable()` para integração com DI container
- Remove dependência direta do modelo Sequelize

**Busca Flexível no Método authenticate**:
- Tenta buscar por email primeiro usando `findByEmail()`
- Se não encontrar, tenta buscar por username usando `findByUsername()`
- Mantém compatibilidade com código existente que pode usar email ou username no campo `email` do DTO

**Uso de findById no Método refresh**:
- Substitui `Usuario.findByPk()` por `usuarioRepository.findById()`
- Mantém a mesma lógica e comportamento

## Comparação: Antes vs Depois

### Antes (Acesso Direto ao Sequelize)

```typescript
import Usuario from '../models/Usuario';

@Injectable()
export class AuthController implements IAuthController {
  async authenticate(req: Request, res: Response): Promise<void> {
    const dto = req.body as CreateLoginDto;

    // Acesso direto ao Sequelize
    const user = await Usuario.findOne({ where: { username: dto.email } });

    if (!user) {
      throw new UnauthorizedException('Credenciais inválidas');
    }
    // ...
  }

  async refresh(req: Request, res: Response): Promise<void> {
    // ...
    const user = await Usuario.findByPk(decoded.id);
    // ...
  }
}
```

**Problemas**:
- ❌ Controller acoplado ao Sequelize
- ❌ Difícil de testar (precisa mockar Sequelize)
- ❌ Violação do padrão Repository
- ❌ Difícil trocar ORM no futuro

### Depois (Com Repository Pattern)

```typescript
import { IUsuarioRepository } from '../infrastructure/repository/IUsuarioRepository';

@Injectable()
export class AuthController implements IAuthController {
  constructor(
    @Inject(TYPES.IUsuarioRepository)
    private usuarioRepository: IUsuarioRepository
  ) {}

  async authenticate(req: Request, res: Response): Promise<void> {
    const dto = req.body as CreateLoginDto;

    // Uso do repositório
    const user = await this.usuarioRepository.findByEmail(dto.email) ||
                 await this.usuarioRepository.findByUsername(dto.email);

    if (!user) {
      throw new UnauthorizedException('Credenciais inválidas');
    }
    // ...
  }

  async refresh(req: Request, res: Response): Promise<void> {
    // ...
    const user = await this.usuarioRepository.findById(decoded.id);
    // ...
  }
}
```

**Benefícios**:
- ✅ Controller desacoplado do Sequelize
- ✅ Fácil de testar (mock do repository)
- ✅ Segue padrão Repository
- ✅ Fácil trocar implementação

### 3. Método authenticate

**Antes**:
```typescript

```

**Depois**:
```typescript

const user = await this.usuarioRepository.findByEmail(dto.email) ||
             await this.usuarioRepository.findByUsername(dto.email);
```

**Razão da Busca Flexível**:
- O DTO tem um campo `email`, mas o código original buscava por `username`
- Para manter compatibilidade, tenta ambos os métodos
- Permite autenticação tanto com email quanto com username

### 4. Método refresh

**Antes**:
```typescript

```

**Depois**:
