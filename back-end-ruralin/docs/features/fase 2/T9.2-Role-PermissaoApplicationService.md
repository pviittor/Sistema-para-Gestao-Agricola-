## Decisões de Implementação

### Abordagem Escolhida

**Application Service Pattern**:
- Separa controllers (HTTP) da lógica de negócio
- Centraliza regras de negócio em um único lugar
- Facilita testes e manutenção
- Reutilizável em diferentes contextos

**Integração com Dependências**:
- Usa `IRoleRepository` e `IPermissaoRepository` para acesso a dados
- Usa `RoleMapper` e `PermissaoMapper` para conversão DTO-Entidade
- Injeta dependências via DI container

**Simplicidade**:
- Role e Permissao são entidades simples, sem relacionamentos complexos
- Não requer lógica de negócio adicional além do CRUD padrão
- Método `findByNome` para busca por nome único

Cria uma nova role.

**Exemplo de Uso**:

```typescript
const role = await service.create({
  nome: 'Administrador',
});
```

```typescript
const role = await service.update(1, {
  nome: 'Administrador Atualizado',

```

Remove uma role.

**Características**:
- Retorna `false` se role não existir
- Retorna `true` se removida com sucesso

Busca uma role por ID.

**Características**:
- Retorna `null` se não encontrada
- Retorna DTO

Lista roles com paginação.

**Características**:
- Paginação padrão: página 1, 10 registros
- Retorna metadados de paginação
- Converte todas as entidades para DTOs

#### `findByNome(nome: string): Promise<RoleResponseDto | null>`

Busca uma role por nome.

**Exemplo de Uso**:
```typescript
const role = await service.findByNome('ADMIN');
```

## Comparação: Antes vs Depois

### Antes (Lógica no Controller)

```typescript
@Injectable()
export class RoleController {
  constructor(
    @Inject(TYPES.IRoleRepository)
    private roleRepository: IRoleRepository
  ) {}

  async create(req: Request, res: Response) {
    // Lógica de negócio no controller ❌
    const dto = req.body as CreateRoleDto;
    const role = await this.roleRepository.create(dto);
    return res.status(201).json(role.toJSON());
  }
}
```

**Problemas**:
- ❌ Lógica de negócio misturada com HTTP
- ❌ Difícil reutilizar em outros contextos
- ❌ Difícil testar isoladamente
- ❌ Conversão manual de entidade para DTO

### Depois (Com Application Service)

```typescript
@Injectable()
export class RoleController {
  constructor(
    @Inject(TYPES.IRoleApplicationService)
    private roleService: IRoleApplicationService
  ) {}

  async create(req: Request, res: Response) {
    // Controller apenas orquestra HTTP ✅
    const dto = req.body as CreateRoleDto;
    const role = await this.roleService.create(dto);
    return res.status(201).json(role);
  }
}
```

**Benefícios**:
- ✅ Controller focado em HTTP
- ✅ Lógica de negócio no service
- ✅ Fácil reutilizar service
- ✅ Fácil testar isoladamente
- ✅ Conversão automática via mapper
