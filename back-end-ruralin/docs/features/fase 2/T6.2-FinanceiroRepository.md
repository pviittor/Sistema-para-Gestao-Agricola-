## Métodos Implementados

### Métodos Customizados

#### `findByPeriodo(dataInicio: Date | string, dataFim: Date | string): Promise<Financeiro[]>`

Busca registros financeiros onde a data de emissão ou vencimento está no período especificado.

**Implementação**:
```typescript
async findByPeriodo(dataInicio: Date | string, dataFim: Date | string): Promise<Financeiro[]> {
  // Converter para string no formato YYYY-MM-DD se necessário
  const dataInicioStr = dataInicio instanceof Date 
    ? dataInicio.toISOString().split('T')[0]
    : dataInicio;
  const dataFimStr = dataFim instanceof Date
    ? dataFim.toISOString().split('T')[0]
    : dataFim;

  return await this.findAll({
    where: {
      [Op.or]: [
        {
          dataEmissao: {
            [Op.between]: [dataInicioStr, dataFimStr],
          },
        },
        {
          dataVencimento: {
            [Op.between]: [dataInicioStr, dataFimStr],
          },
        },
      ],
    },
    order: [['dataEmissao', 'ASC'], ['dataVencimento', 'ASC']],
  });
}
```

**Exemplo de Uso**:
```typescript
// Com Date
const registros = await financeiroRepository.findByPeriodo(
  new Date('2025-01-01'),
  new Date('2025-01-31')
);

// Com string
const registros = await financeiroRepository.findByPeriodo(
  '2025-01-01',
  '2025-01-31'
);
```

**Lógica de Busca**:
- Busca registros onde `dataEmissao` está no período OU
- Busca registros onde `dataVencimento` está no período
- Retorna todos os registros que atendem qualquer uma das condições

**Casos de Uso**:
- Relatórios financeiros por período
- Extratos mensais
- Análise de fluxo de caixa
- Relatórios de vencimentos

#### `findByTipo(tipo: string): Promise<Financeiro[]>`

Busca registros financeiros por tipo (RECEITA ou DESPESA), determinado pelo sinal do valor.

**Implementação**:
```typescript
async findByTipo(tipo: string): Promise<Financeiro[]> {
  const tipoUpper = tipo.toUpperCase();
  
  // Determinar operador baseado no tipo
  // RECEITA: valor >= 0
  // DESPESA: valor < 0
  const whereCondition = tipoUpper === 'RECEITA'
    ? { valor: { [Op.gte]: 0 } }
    : { valor: { [Op.lt]: 0 } };

  return await this.findAll({
    where: whereCondition,
    order: [['dataEmissao', 'DESC']],
  });
}
```

**Exemplo de Uso**:
```typescript
// Buscar receitas
const receitas = await financeiroRepository.findByTipo('RECEITA');

// Buscar despesas
const despesas = await financeiroRepository.findByTipo('DESPESA');

// Aceita minúsculas também
const receitas2 = await financeiroRepository.findByTipo('receita');
```

**Lógica de Tipo**:
- **RECEITA**: Valores >= 0 (positivos ou zero)
- **DESPESA**: Valores < 0 (negativos)

**Casos de Uso**:
- Listar apenas receitas
- Listar apenas despesas
- Relatórios por tipo
- Cálculo de saldo (receitas - despesas)

## Detalhes de Implementação

### Busca por Período

O método `findByPeriodo` utiliza `Op.or` e `Op.between` para buscar registros onde qualquer uma das datas está no período:

```typescript
where: {
  [Op.or]: [
    {
      dataEmissao: {
        [Op.between]: [dataInicioStr, dataFimStr],
      },
    },
    {
      dataVencimento: {
        [Op.between]: [dataInicioStr, dataFimStr],
      },
    },
  ],
}
```

**Características**:
- Busca inclusiva (inclui dataInicio e dataFim)
- Retorna registros onde `dataEmissao` OU `dataVencimento` está no período
- Ordena por data de emissão e depois por data de vencimento (ambas crescentes)

### Busca por Tipo

O método `findByTipo` determina o tipo baseado no sinal do valor:

```typescript
const whereCondition = tipoUpper === 'RECEITA'
  ? { valor: { [Op.gte]: 0 } }  // Valores >= 0
  : { valor: { [Op.lt]: 0 } };   // Valores < 0
```

**Características**:
- RECEITA: valores >= 0 (positivos ou zero)
- DESPESA: valores < 0 (negativos)
- Aceita tipo em maiúsculas ou minúsculas
- Ordena por data de emissão (mais recentes primeiro)

**Nota**: Esta implementação assume que o tipo é determinado pelo sinal do valor. Se no futuro houver um campo `tipo` explícito no modelo, o método pode ser atualizado para usar esse campo.

## Testes Unitários

### Estrutura de Testes

Os testes verificam:
1. **findByPeriodo**: Retorna registros no período, com conversão de Date para string
2. **findByPeriodo com strings**: Aceita strings como parâmetros
3. **findByTipo RECEITA**: Retorna registros com valor >= 0
4. **findByTipo DESPESA**: Retorna registros com valor < 0
5. **findByTipo case-insensitive**: Aceita tipo em minúsculas
6. **Métodos herdados**: Verifica que métodos do BaseRepository estão disponíveis

### Exemplo de Teste

```typescript
describe('FinanceiroRepository', () => {
  let repository: FinanceiroRepository;
  let mockFindAll: jest.Mock;

  beforeEach(() => {
    repository = new FinanceiroRepository();
    mockFindAll = jest.fn();
    (repository as any).findAll = mockFindAll;
  });

  it('deve retornar receitas quando tipo é RECEITA', async () => {
    const mockReceitas = [
      { id: 1, valor: 1000, dataEmissao: '2025-01-15' },
    ] as Financeiro[];
    mockFindAll.mockResolvedValue(mockReceitas);

    const result = await repository.findByTipo('RECEITA');

    expect(result).toBe(mockReceitas);
    expect(mockFindAll).toHaveBeenCalledWith({
      where: {
        valor: {
          [Op.gte]: 0,
        },
      },
      order: [['dataEmissao', 'DESC']],
    });
  });
```

## Comparação: Antes vs Depois

### Antes (Acesso Direto ao Sequelize)

```typescript
// Controller
class FinanceiroController {
  async getByPeriodo(req: Request, res: Response) {
    const { dataInicio, dataFim } = req.query;
    
    // Acesso direto ao Sequelize
    const registros = await Financeiro.findAll({
      where: {
        [Op.or]: [
          { dataEmissao: { [Op.between]: [dataInicio, dataFim] } },
          { dataVencimento: { [Op.between]: [dataInicio, dataFim] } },
        ],
      },
    });
    
    return res.json(registros);
  }
}
```

**Problemas**:
- ❌ Controller acoplado ao Sequelize
- ❌ Código duplicado em múltiplos lugares
- ❌ Difícil de testar

### Depois (Com Repository Pattern)

```typescript
// Controller
@Injectable()
class FinanceiroController {
  constructor(
    @Inject(TYPES.IFinanceiroRepository)
    private financeiroRepository: IFinanceiroRepository
  ) {}

  async getByPeriodo(req: Request, res: Response) {
    const { dataInicio, dataFim } = req.query;
    
    // Uso do repositório
    const registros = await this.financeiroRepository.findByPeriodo(
      dataInicio as string,
      dataFim as string
    );
    
    return res.json(registros);
  }
}
```

**Benefícios**:
- ✅ Controller desacoplado do Sequelize
- ✅ Código reutilizável
- ✅ Fácil de testar
