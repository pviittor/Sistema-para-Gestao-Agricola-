## Implementação Detalhada

### CreateLembreteDto

```typescript
export class CreateLembreteDto extends CreateDto {
  @IsString({ message: 'Descrição simples deve ser uma string' })
  @IsNotEmpty({ message: 'Descrição simples é obrigatória' })
  desc_simples!: string;

  @IsString({ message: 'Descrição completa deve ser uma string' })
  @IsNotEmpty({ message: 'Descrição completa é obrigatória' })
  desc_completa!: string;

  @IsArray({ message: 'Lembrete data hora deve ser um array' })
  @IsOptional()
  @ArrayMinSize(1, { message: 'Lembrete data hora deve ter pelo menos um item se fornecido' })
  @ValidateNested({ each: true })
  @Type(() => CreateLembreteDataHoraDto)
  lembrete_data_hora?: CreateLembreteDataHoraDto[];
}
```

### CreateLembreteDataHoraDto

```typescript
export class CreateLembreteDataHoraDto {
  @IsString({ message: 'Dia deve ser uma string' })
  @IsOptional()
  dia?: string;

  @IsDateString({}, { message: 'Data deve ser uma data válida no formato YYYY-MM-DD' })
  @IsOptional()
  data?: string;

  @IsString({ message: 'Horário deve ser uma string' })
  @IsNotEmpty({ message: 'Horário é obrigatório' })
  @Matches(/^([0-1][0-9]|2[0-3]):[0-5][0-9]:[0-5][0-9]$/, {
    message: 'Horário deve estar no formato HH:mm:ss',
  })
  horario!: string;
}
```

## Validação de Arrays Aninhados

### Funcionamento

A validação de arrays aninhados usa:
- `@IsArray()`: Valida que é um array
- `@ArrayMinSize(1)`: Garante que se fornecido, tenha pelo menos um item
- `@ValidateNested({ each: true })`: Valida cada item do array
- `@Type(() => CreateLembreteDataHoraDto)`: Transforma cada item em instância do DTO

### Implementação

```typescript
@IsArray({ message: 'Lembrete data hora deve ser um array' })
@IsOptional()
@ArrayMinSize(1, { message: 'Lembrete data hora deve ter pelo menos um item se fornecido' })
@ValidateNested({ each: true })
@Type(() => CreateLembreteDataHoraDto)
lembrete_data_hora?: CreateLembreteDataHoraDto[];
```

**Comportamento**:
- Se `lembrete_data_hora` não for fornecido, é válido (opcional)
- Se for fornecido como array vazio, é inválido (deve ter pelo menos um item)
- Cada item do array é validado individualmente como `CreateLembreteDataHoraDto`

## Padrões de Formato

### Data

Formato: `YYYY-MM-DD`

**Exemplos**:
- ✅ `2025-01-20` - Válido
- ✅ `2025-12-31` - Válido
- ❌ `20-01-2025` - Inválido
- ❌ `2025/01/20` - Inválido

### Horário

Formato: `HH:mm:ss`

**Exemplos**:
- ✅ `09:00:00` - Válido
- ✅ `23:59:59` - Válido
- ❌ `9:00:00` - Inválido (deve ter dois dígitos)
- ❌ `25:00:00` - Inválido (hora > 23)
- ❌ `09:60:00` - Inválido (minuto > 59)

### Dia

Formato: String livre (ex: "Segunda-feira", "Monday", etc.)

## Padrões e Boas Práticas

### 1. Sempre Use DTOs em Rotas

```typescript
// ✅ Bom
router.post('/', validateDto(CreateLembreteDto), handler);

// ⚠️ Evitar
router.post('/', handler); // Sem validação
```

### 2. Use @Type() para Arrays Aninhados

```typescript
// ✅ Bom
@ValidateNested({ each: true })
@Type(() => CreateLembreteDataHoraDto)
lembrete_data_hora?: CreateLembreteDataHoraDto[];

// ⚠️ Evitar
@ValidateNested({ each: true })
lembrete_data_hora?: CreateLembreteDataHoraDto[]; // Sem @Type(), não transforma
```

### 3. Use @ArrayMinSize() para Arrays Opcionais

```typescript
// ✅ Bom
@IsOptional()
@ArrayMinSize(1, { message: 'Array deve ter pelo menos um item se fornecido' })
lembrete_data_hora?: CreateLembreteDataHoraDto[];

// ⚠️ Evitar
@IsOptional()
lembrete_data_hora?: CreateLembreteDataHoraDto[]; // Permite array vazio
```

### 4. Lance Exceções ao Invés de Respostas Diretas

```typescript
// ✅ Bom
if (!lembrete) {
  throw new NotFoundException('Lembrete', id);
}

// ⚠️ Evitar
if (!lembrete) {
  res.status(404).json({ error: 'Lembrete não encontrado' });
  return;
}
```

### 5. Gerencie Arrays de Relacionamentos Corretamente

```typescript
// ✅ Bom
if (lembrete_data_hora) {
  await LembreteDataHora.destroy({ where: { lembreteId: id } });
  if (Array.isArray(lembrete_data_hora)) {
    const items = lembrete_data_hora.map((item: any) => {
      const itemData: any = { lembreteId: id, horario: item.horario };
      if (item.dia !== undefined) itemData.dia = item.dia;
      if (item.data !== undefined) itemData.data = item.data;
      return itemData;
    });
    await LembreteDataHora.bulkCreate(items);
  }
}

// ⚠️ Evitar
await LembreteDataHora.destroy({ where: { lembreteId: id } });
await LembreteDataHora.bulkCreate(lembrete_data_hora); // Pode passar undefined
```

## Troubleshooting

### Problema: Validação de array aninhado não funciona

**Sintomas**: Array com itens inválidos passa na validação

**Solução**:
1. Verificar se `@ValidateNested({ each: true })` está aplicado
2. Verificar se `@Type()` está aplicado corretamente
3. Verificar se `validateNested: true` está habilitado no middleware

### Problema: Array vazio passa na validação

**Sintomas**: Array vazio passa mesmo quando não deveria

**Solução**:
1. Verificar se `@ArrayMinSize(1)` está aplicado
2. Verificar se `@IsOptional()` está antes de `@ArrayMinSize()`
3. Verificar se a mensagem de erro está clara

### Problema: Horário inválido passa na validação

**Sintomas**: Horário em formato incorreto passa na validação

**Solução**:
1. Verificar se `@Matches()` está com regex correto
2. Verificar se `transform: true` está habilitado no middleware
3. Verificar se o formato está correto (HH:mm:ss)
