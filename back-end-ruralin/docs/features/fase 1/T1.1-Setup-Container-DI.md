- `experimentalDecorators`: Habilita suporte a decorators
- `emitDecoratorMetadata`: Emite metadados necessários para injeção automática de tipos

### 3. Container de DI (`src/core/di/container.ts`)

O container é configurado e exportado para uso em toda a aplicação:

```typescript
import 'reflect-metadata';
import { container as tsyringeContainer } from 'tsyringe';

export const container = tsyringeContainer;

export function initializeContainer(): void {
  // Registro de dependências será feito aqui conforme implementação
  console.log('Dependency Injection container initialized');
}
```

**Características**:
- Container singleton global
- Função `initializeContainer()` para setup inicial
- Função `clearContainer()` para testes

### 4. Decorators Customizados (`src/core/di/decorators.ts`)

Decorators wrappers sobre TSyringe para padronização:

```typescript
export function Injectable(scope: 'singleton' | 'transient' = 'singleton') {
  return function (target: any) {
    tsyringeInjectable()(target);
  };
}

export function Inject(token: string | symbol | Function) {
  return tsyringeInject(token);
}
```

**Uso**:
```typescript
@Injectable()
export class MyService {
  constructor(
    @Inject(TYPES.ILogger) private logger: ILogger
  ) {}
}
```

### 5. Tokens de DI (`src/core/di/types.ts`)

Tokens definidos para todas as dependências do sistema:

```typescript
export const TYPES = {
  ILogger: Symbol.for('ILogger'),
  IUsuarioRepository: Symbol.for('IUsuarioRepository'),
  // ... outros tokens
} as const;
```

**Benefícios**:
- Evita problemas de referência circular
- Facilita manutenção
- Type-safe com TypeScript

## Exemplos de Uso

### Exemplo 1: Criar um Service com DI

```typescript
import { Injectable, Inject } from '../core/di';
import { TYPES } from '../core/di/types';

export interface ILogger {
  log(message: string): void;
}

@Injectable()
export class LoggerService implements ILogger {
  log(message: string): void {
    console.log(message);
  }
}

@Injectable()
export class MyService {
  constructor(
    @Inject(TYPES.ILogger) private logger: ILogger
  ) {}

  doSomething(): void {
    this.logger.log('Doing something...');
  }
}
```

### Exemplo 2: Registrar e Resolver Dependências

```typescript
import { container, TYPES } from './core/di';
import { LoggerService, ILogger } from './services';

// Registrar dependência
container.registerSingleton<ILogger>(TYPES.ILogger, LoggerService);

// Resolver dependência
const logger = container.resolve<ILogger>(TYPES.ILogger);
```

### Exemplo 3: Usar em Controllers

```typescript
import { Injectable, Inject } from '../core/di';
import { TYPES } from '../core/di/types';

@Injectable()
export class UsuarioController {
  constructor(
    @Inject(TYPES.IUsuarioApplicationService) 
    private usuarioService: IUsuarioApplicationService
  ) {}

  async create(req: Request, res: Response) {
    const result = await this.usuarioService.create(req.body);
    return res.json(result);
  }
}
```

## Notas de Manutenção

### Adicionar Nova Dependência

1. Adicionar token em `src/core/di/types.ts`:
   ```typescript
   export const TYPES = {
     // ...
     IMyNewService: Symbol.for('IMyNewService'),
   } as const;
   ```

2. Registrar no `initializeContainer()`:
   ```typescript
   container.registerSingleton<IMyNewService>(
     TYPES.IMyNewService, 
     MyNewService
   );
   ```

3. Usar com `@Inject`:
   ```typescript
   @Injectable()
   export class MyClass {
     constructor(
       @Inject(TYPES.IMyNewService) private myService: IMyNewService
     ) {}
   }
   ```

### Troubleshooting

**Problema**: Decorators não funcionam
- **Solução**: Verificar se `reflect-metadata` está importado no início do arquivo de entrada

**Problema**: Erro "Cannot find module 'reflect-metadata'"
- **Solução**: Executar `npm install reflect-metadata`

**Problema**: Erro de compilação sobre decorators
- **Solução**: Verificar se `tsconfig.json` tem `experimentalDecorators: true`
