### Problemas de Troubleshooting Documentados

1. **Erro de Compilação**: Decorator não encontrado
   - Causa: Import faltando ou configuração TypeScript
   - Solução: Verificar imports e tsconfig.json

2. **Dependência Não Encontrada**: "No matching bindings"
   - Causa: Dependência não registrada
   - Solução: Verificar registro no container

3. **Dependência Circular**: Erro de dependência circular
   - Causa: Duas classes dependem uma da outra
   - Solução: Usar interfaces ou refatorar

4. **Múltiplas Instâncias**: Singleton não funciona
   - Causa: Scope incorreto ou instanciação manual
   - Solução: Verificar decorator e não criar manualmente

5. **Dependência Undefined**: Dependência é undefined
   - Causa: Não registrada ou token incorreto
   - Solução: Verificar registro e token

6. **Erro de Tipo**: Property não existe
   - Causa: Interface não corresponde à implementação
   - Solução: Verificar assinaturas de métodos

### Boas Práticas Documentadas

1. Sempre usar interfaces
2. Registrar todas as dependências centralizadamente
3. Usar tokens do TYPES
4. Documentar dependências complexas
5. Limpar container em testes
6. Preferir singleton para services stateless
7. Evitar resolver no código de negócio
