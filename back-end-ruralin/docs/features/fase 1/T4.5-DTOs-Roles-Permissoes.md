## Decisões de Implementação

### Abordagem Escolhida

**Validação de Unicidade**: Implementado usando `IsUnique` para garantir que nomes de roles e permissões sejam únicos:
- Validação assíncrona no banco de dados
- Suporte para exclusão de registro atual em updates

**Validação de Formato**: Implementado regex para permissões:
- Formato recomendado: `recurso.acao` (ex: `usuarios.criar`)
- Apenas letras minúsculas, números, pontos, underscores e hífens
- Garante consistência no formato de permissões

**Refatoração para DI**: 
- Controllers convertidos de classes singleton para classes com `@Injectable()`
- Interfaces criadas para ambos os controllers
- Registro no DI container

**DTOs Específicos**:
- `CreateRoleDto`: Campo obrigatório com validações completas
- `UpdateRoleDto`: Campo opcional para atualizações parciais
- `CreatePermissaoDto`: Campo obrigatório com validações de formato
- `UpdatePermissaoDto`: Campo opcional para atualizações parciais

## Formato de Nome de Permissão

### Padrão Recomendado

Formato: `recurso.acao`

**Exemplos**:
- ✅ `usuarios.criar` - Válido
- ✅ `usuarios.editar` - Válido
- ✅ `usuarios.deletar` - Válido
- ✅ `eventos.listar` - Válido
- ✅ `financeiros.visualizar` - Válido
- ✅ `recurso_acao.acao-teste` - Válido (com underscore e hífen)
- ✅ `recurso123.acao456` - Válido (com números)
- ❌ `Usuarios.Criar` - Inválido (maiúsculas)
- ❌ `usuarios@criar` - Inválido (caractere especial)
- ❌ `usuarios criar` - Inválido (espaço)
- ❌ `usuarios#criar` - Inválido (caractere especial)

### Regex Utilizado

```typescript
/^[a-z0-9._-]+$/
```

**Caracteres Permitidos**:
- Letras minúsculas: `a-z`
- Números: `0-9`
- Ponto: `.`
- Underscore: `_`
- Hífen: `-`

## Troubleshooting

### Problema: Validação de unicidade não funciona

**Sintomas**: Nome duplicado passa na validação

**Solução**:
1. Verificar se `@IsUnique()` está aplicado corretamente
2. Verificar se o modelo Sequelize está registrado corretamente
3. Verificar se o nome do modelo está correto ('Role' vs 'Roles')
4. Verificar logs de erro do validador

### Problema: Validação de formato não funciona para permissões

**Sintomas**: Nome com formato incorreto passa na validação

**Solução**:
1. Verificar se `@Matches()` está aplicado corretamente
2. Verificar se o regex está correto (`/^[a-z0-9._-]+$/`)
3. Verificar se `transform: true` está habilitado no middleware

### Problema: Controller não é resolvido do DI container

**Sintomas**: Erro ao resolver controller

**Solução**:
1. Verificar se o controller está registrado em `registerControllers()`
2. Verificar se `initializeContainer()` foi chamado antes das rotas
3. Verificar se o token em `TYPES` está correto
4. Verificar se o controller tem `@Injectable()`
