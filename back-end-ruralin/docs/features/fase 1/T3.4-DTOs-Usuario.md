## Implementação Detalhada

### Validador Customizado IsUnique

```typescript
@ValidatorConstraint({ async: true })
export class IsUniqueConstraint implements ValidatorConstraintInterface {
  async validate(value: any, args: ValidationArguments): Promise<boolean> {
    const [modelName, columnName, excludeId] = args.constraints;
    
    // Buscar no banco de dados
    const Model = sequelize.models[modelName];
    const where: any = { [columnName]: value };
    
    // Excluir registro atual se excludeId fornecido
    if (excludeId === 'id') {
      const idValue = object._updateId || object.id;
      if (idValue) {
        where.id = { [Op.ne]: idValue };
      }
    }
    
    const existing = await Model.findOne({ where });
    return !existing; // Retorna true se único
  }
}
```

**Uso**:
```typescript
// Para criação
@IsUnique('Usuario', 'email', undefined, { message: 'Email já está em uso' })
email!: string;

// Para atualização (exclui o próprio registro)
@IsUnique('Usuario', 'email', 'id', { message: 'Email já está em uso' })
email?: string;
```

### CreateUsuarioDto

```typescript
export class CreateUsuarioDto extends CreateDto {
  @IsString({ message: 'Nome deve ser uma string' })
  @IsNotEmpty({ message: 'Nome é obrigatório' })
  nome!: string;

  @IsEmail({}, { message: 'Email deve ser um email válido' })
  @IsNotEmpty({ message: 'Email é obrigatório' })
  @IsUnique('Usuario', 'email', undefined, { message: 'Email já está em uso' })
  email!: string;

  @IsString({ message: 'Username deve ser uma string' })
  @IsNotEmpty({ message: 'Username é obrigatório' })
  @IsUnique('Usuario', 'username', undefined, { message: 'Username já está em uso' })
  username!: string;

  @IsString({ message: 'Senha deve ser uma string' })
  @IsNotEmpty({ message: 'Senha é obrigatória' })
  @MinLength(8, { message: 'Senha deve ter no mínimo 8 caracteres' })
  @Matches(/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/, {
    message: 'Senha deve conter pelo menos uma letra maiúscula, uma minúscula e um número',
  })
  senha!: string;

  @IsEnum(UsuarioTipo, { message: 'Tipo deve ser ROOT ou CLIENT' })
  @IsNotEmpty({ message: 'Tipo é obrigatório' })
  tipo!: UsuarioTipo;

  // ... outros campos
}
```

## Validador Customizado IsUnique

### Funcionamento

O validador `IsUnique` verifica se um valor é único no banco de dados:

1. **Para Criação**: Verifica se já existe algum registro com o valor
2. **Para Atualização**: Verifica se existe outro registro (excluindo o atual) com o valor

### Implementação

```typescript
@IsUnique('Usuario', 'email', excludeId, { message: 'Email já está em uso' })
```

**Parâmetros**:
- `modelName`: Nome do modelo Sequelize ('Usuario')
- `columnName`: Nome da coluna ('email', 'username')
- `excludeId`: 
  - `undefined`: Para criação (não exclui nenhum registro)
  - `'id'`: Para atualização (exclui registro com mesmo ID)
- `validationOptions`: Opções do class-validator

### Exemplo de Uso

```typescript
// CreateUsuarioDto
@IsUnique('Usuario', 'email', undefined, { message: 'Email já está em uso' })
email!: string;

// UpdateUsuarioDto
@IsUnique('Usuario', 'email', 'id', { message: 'Email já está em uso' })
email?: string;
```

## Middleware validateDtoUpdate

Criado middleware especializado para updates que passa o ID do request params para o DTO:

```typescript
export function validateDtoUpdate(
  dtoClass: new () => any,
  idParamName: string = 'id',
  options?: ValidationOptions
)
```

**Funcionalidades**:
- Extrai ID de `req.params[idParamName]`
- Passa ID para o DTO como `_updateId` e `id`
- Permite que validadores customizados excluam o registro atual
- Remove campos auxiliares antes de passar para o controller

## Padrões de Senha

A senha deve atender aos seguintes critérios:
- ✅ Mínimo 8 caracteres
- ✅ Pelo menos uma letra minúscula (a-z)
- ✅ Pelo menos uma letra maiúscula (A-Z)
- ✅ Pelo menos um número (0-9)

**Regex**: `/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/`

**Exemplos**:
- ✅ `Senha123` - Válida
- ✅ `MinhaSenha456` - Válida
- ❌ `senha123` - Sem maiúscula
- ❌ `SENHA123` - Sem minúscula
- ❌ `SenhaABC` - Sem número
- ❌ `Sen123` - Menos de 8 caracteres

## Troubleshooting

### Problema: Validação de unicidade não funciona em updates

**Sintomas**: Email/username duplicado passa na validação em updates

**Solução**:
1. Verificar se está usando `validateDtoUpdate()` ao invés de `validateDto()`
2. Verificar se `@IsUnique()` está usando `excludeId: 'id'`
3. Verificar se o ID está sendo passado corretamente do request params

### Problema: Validação de unicidade muito lenta

**Sintomas**: Validação demora muito tempo

**Solução**:
1. Verificar se há índices no banco de dados para email e username
2. Considerar cache para validações frequentes
3. Verificar se não há queries N+1

### Problema: Senha não está sendo validada corretamente

**Sintomas**: Senha inválida passa na validação

**Solução**:
1. Verificar se todos os decorators estão aplicados
2. Verificar se `@Matches()` está com regex correto
3. Verificar se `transform: true` está habilitado

### Problema: Validação de unicidade retorna falso positivo

**Sintomas**: Validação falha mesmo quando valor é único

**Solução**:
1. Verificar se o modelo Sequelize está registrado corretamente
2. Verificar se o nome do modelo está correto ('Usuario' vs 'usuarios')
3. Verificar logs de erro do validador
