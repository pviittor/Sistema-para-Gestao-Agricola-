## Implementação Detalhada

### Interface ILogger

```typescript
export interface ILogger {
  debug(message: string, meta?: Record<string, any>): void;
  info(message: string, meta?: Record<string, any>): void;
  warn(message: string, meta?: Record<string, any>): void;
  error(message: string, meta?: Record<string, any>): void;
}
```

### LoggerService

```typescript
@Injectable()
export class LoggerService implements ILogger {
  private logger: Logger;

  constructor(config?: LoggerConfig) {
    const level = config?.level || process.env.LOG_LEVEL || 'info';
    const environment = config?.environment || process.env.NODE_ENV || 'development';

    const pinoConfig: pino.LoggerOptions = {
      level,
      base: {
        name: appName,
        env: environment,
      },
      timestamp: pino.stdTimeFunctions.isoTime,
    };

    // Desenvolvimento: pretty print
    if (environment === 'development') {
      this.logger = pino(pinoConfig, pino.transport({
        target: 'pino-pretty',
        options: {
          colorize: true,
          translateTime: 'HH:MM:ss Z',
        },
      }));
    } else {
      // Produção: JSON puro
      this.logger = pino(pinoConfig);
    }
  }

  debug(message: string, meta?: Record<string, any>): void {
    if (meta) {
      this.logger.debug(meta, message);
    } else {
      this.logger.debug(message);
    }
  }

  // ... outros métodos
}
```

### Registro no Container

```typescript
// src/core/di/registerServices.ts

  container.registerSingleton(TYPES.ILogger, LoggerService);
}
```

### Exemplo 4: Log em Service com DI

```typescript
import { Injectable, Inject } from '../core/di';
import { TYPES } from '../core/di/types';
import { ILogger } from '../core/logger/ILogger';

@Injectable()
export class OrderService {
  constructor(
    @Inject(TYPES.ILogger) private logger: ILogger
  ) {}

  async processOrder(orderId: number): Promise<void> {
    this.logger.info('Processing order', { orderId });

    try {
      // Processar pedido...
      this.logger.info('Order processed successfully', { orderId });
    } catch (error: any) {
      this.logger.error('Failed to process order', {
        orderId,
        error: error.message,
        stack: error.stack,
      });
      throw error;
    }
  }
}
```

## Configuração

### Variáveis de Ambiente

```env

NODE_ENV=development

# Nome da aplicação (aparece nos logs)
APP_NAME=ruralin-backend
```

### Níveis de Log

- **debug**: Informações detalhadas para desenvolvimento
- **info**: Eventos normais da aplicação (padrão)
- **warn**: Situações que merecem atenção
- **error**: Erros e exceções

## Padrões e Boas Práticas

### 1. Sempre Use Metadados Estruturados

```typescript
// ✅ Bom
logger.info('User created', {
  userId: 123,
  email: 'user@example.com',
});

// ⚠️ Evitar
logger.info(`User created: ${userId} - ${email}`);
```

### 2. Use Níveis Apropriados

```typescript
// ✅ Debug - Informações detalhadas
logger.debug('Query executed', { sql: query, params });

// ✅ Info - Eventos normais
logger.info('User logged in', { userId });

// ✅ Warn - Atenção necessária
logger.warn('Low balance', { userId, balance: 10 });

// ✅ Error - Erros e exceções
logger.error('Database error', { error: err.message, stack: err.stack });
```

### 3. Inclua Contexto Relevante

```typescript
// ✅ Bom - Contexto completo
logger.error('Payment failed', {
  userId: 123,
  orderId: 456,
  amount: 100.50,
  error: error.message,
  stack: error.stack,
});

// ⚠️ Evitar - Contexto insuficiente
logger.error('Payment failed');
```

### 4. Não Logue Informações Sensíveis

```typescript
// ❌ Errado - Senha em log
logger.info('User created', {
  email: 'user@example.com',
  senha: 'senha123', // NUNCA fazer isso!
});

// ✅ Correto
logger.info('User created', {
  email: 'user@example.com',
  userId: 123,
});
```

### 5. Use Logger em Todos os Services

```typescript
@Injectable()
export class MyService {
  constructor(
    @Inject(TYPES.ILogger) private logger: ILogger
  ) {}

  async doSomething(): Promise<void> {
    this.logger.info('Starting operation');
    // ...
  }
}
```

## Troubleshooting

### Problema: Logs não aparecem

**Sintomas**: Nenhum log sendo exibido

**Solução**:
1. Verificar nível de log (`LOG_LEVEL`)
2. Verificar se Logger está registrado no container
3. Verificar se `initializeContainer()` foi chamado

### Problema: Logs em formato errado

**Sintomas**: Logs não estão formatados como esperado

**Solução**:
1. Verificar `NODE_ENV`
2. Verificar se `pino-pretty` está instalado
3. Verificar configuração do Pino

### Problema: Logger não injetado

**Sintomas**: Erro "No matching bindings found"

**Solução**:
1. Verificar se Logger está registrado em `registerServices()`
2. Verificar se `registerServices()` é chamado antes de `registerControllers()`
3. Verificar token `TYPES.ILogger`
